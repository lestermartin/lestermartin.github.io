YARN

Kill a hadoop job:

yarn application -kill $ApplicationId

You can get a list of all ApplicationId's doing:

yarn application -list

Random Notes

dfs.datanode.max.transfer.threads - default is 1024, but bump to >= 4096 or >= 16K for HBase
